# MSU Draft — помощник пика для турнира МГУ по Dota 2

Статический сайт (HTML + JS, без сборки). Вносишь пики/баны соперника и союзников по ходу драфта, сайт советует лучших героев на каждую свободную позицию.

## Как считается рекомендация
- **Пул игрока** — бонус героям, на которых игрок уверенно играет (вес настраивается в «Команда»).
- **Мета** — винрейт в Divine + Immortal и частота пиков/банов в про-матчах с [OpenDota](https://www.opendota.com) (обновляется раз в 12 ч, кэшируется в браузере).
- **Контрпики** — матчапы OpenDota против каждого вражеского героя + встроенная база контрпиков (`data/meta.js`).
- **Синергия и состав** — известные связки, наличие инициации, контроля, сейва, пуша, баланс маг./физ. урона.
- Блок «Стоит забанить» — сильные в мете герои, опасные для наших пиков и пулов.

Если OpenDota недоступна, работает встроенная оффлайн-база. Для каждого героя есть ссылки на Dotabuff и STRATZ.

## Запуск
Открыть `index.html` в браузере или включить GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Управление
- Нажми на слот → поиск героя (понимает русские прозвища: «гуля», «сф», «белка», «легионка»…), Enter — выбрать.
- Начни печатать где угодно — быстро добавишь пик соперника.
- Клик по рекомендации — пик на выбранную позицию.
- Составы, пулы и веса меняются в «Команда» и сохраняются в браузере.

Пулы по умолчанию — `data/team.js`.
