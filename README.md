# MSU Draft — помощник пика для турнира МГУ по Dota 2

Статический сайт (HTML + JS, без сборки). Вносишь пики/баны соперника и союзников по ходу драфта, сайт советует лучших героев на каждую свободную позицию.

## Captains Mode
Сайт ведёт драфт по порядку CM (24 хода: 3 фазы банов и пиков, по 7 банов и 5 пиков на команду). Перед драфтом выбери «Мы — 1-й пик / 2-й пик».
- В каждый ход блок рекомендаций показывает нужное: наш бан → кого банить, наш пик → лучшие герои на все свободные позиции (позицию сайт назначает сам, ⇅ на герое — поменять), ход соперника → чего ждать.
- В первой фазе пиков бонус гибким героям, которые скрывают позиции, и штраф героям, которых легко законтрить; последний пик — упор на контрпик.
- Таймер хода 30 с и резерв 130 с на команду (запуск — «Таймер»), Ctrl+Z или «Отменить» — шаг назад.

## Как считается рекомендация
- **Пул игрока** — бонус героям, на которых игрок уверенно играет (вес настраивается в «Команда»).
- **Мета** — винрейт в Divine + Immortal и частота пиков/банов в про-матчах с [OpenDota](https://www.opendota.com) (обновляется раз в 12 ч, кэшируется в браузере).
- **Контрпики** — матчапы OpenDota против каждого вражеского героя + встроенная база контрпиков (`data/meta.js`).
- **Синергия и состав** — известные связки, наличие инициации, контроля, сейва, пуша, баланс маг./физ. урона.
- Блок «Стоит забанить» — сильные в мете герои, опасные для наших пиков и пулов (клик — в наши баны).
- **Предметы под драфт** — у каждого нашего героя основа сборки (популярные предметы с OpenDota, иначе `data/builds.js`) и ситуативные предметы против текущих пиков соперника: Lotus/Linken's против направленных контролей, BKB/Pipe/Glimmer против магии, MKB против уклонения, Vessel/Skadi против хила, Silver Edge против пассивок, Dust/Sentry против невидимости и т. д. Правила — в `data/builds.js`.
- **Баны** — отдельно наши и соперника; забаненные и уже взятые герои пропадают из выбора и из рекомендаций.

Если OpenDota недоступна, работает встроенная оффлайн-база. Для каждого героя есть ссылки на Dotabuff и STRATZ.

## Запуск
Открыть `index.html` в браузере или включить GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Управление
- «Выбрать героя» или просто начни печатать → поиск героя для текущего хода (понимает русские прозвища: «гуля», «сф», «белка», «легионка»…), Enter — выбрать.
- Начни печатать где угодно — быстро добавишь пик соперника.
- Клик по рекомендации — пик на выбранную позицию.
- Составы, пулы и веса меняются в «Команда» и сохраняются в браузере.

Пулы по умолчанию — `data/team.js`.
